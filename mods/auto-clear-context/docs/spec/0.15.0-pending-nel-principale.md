# 0.15.0 — pending nel repo principale e avviso se manca

## Problema (report 2026-11-23 §1, §5.5, §7)
Tre handoff non rilanciati il 23–24/11: pending non scritto (10:25, 10:39) o scritto in
`.worktrees/wt-*/.claude/handoff/pending/` (01:10 del 24). Causa: tutti i percorsi dati a skill e agenti sono
relativi (`.claude/handoff/pending/…`); chi lavora in un worktree (cwd del teammate, `cd` della principale) lo scrive
lì, mentre la mod legge solo `$.session.root()/.claude/handoff/`. Se il file manca la mod non dice niente.

## Comportamento atteso
1. **Radice del repo principale.** `paths($)` risolve la radice con
   `git rev-parse --path-format=absolute --git-common-dir` (cwd = `$.session.root()`), via `$.process.run`: se
   l'uscita è 0 e il percorso finisce con `/.git`, la radice è la sua cartella madre; altrimenti (non git, repo bare,
   errore, `$.process` assente) resta `$.session.root()`. Risultato in cache per radice di sessione.
2. **Percorsi assoluti** in tutte le note (principale e agenti), nella riga HANDOFF e in `agentPaths`.
3. **Recupero dal worktree.** Se l'handoff non è nella radice principale, la mod lo cerca anche in
   `<cwd dell'agente>/.claude/handoff/pending/` (AgentInfo.cwd) e, per la principale, in `$.session.cwd()` e
   `$.session.root()`; se lo trova lì lo usa e scrive una riga nel log («handoff trovato fuori dal repo principale»).
4. **Avviso se manca o è vuoto.** Dopo una nota di handoff (zona) a una sessione o a un agente:
   - a fine turno di chi l'ha ricevuta, se la risposta contiene `HANDOFF` (o la skill ha chiuso il turno) e il file
     è assente o vuoto → avviso subito;
   - altrimenti un timer di `handoffWaitSeconds` (nuova opzione, default 180, 0 = spento) dalla nota: allo
     scadere, se il file è ancora assente o vuoto e chi ha ricevuto la nota non è in un turno → avviso.
   Avviso: all'agente con `$.session.send({ to: { agentId } })` e, per un subagent o se l'invio fallisce, alla
   principale (`leadNotes`); alla principale con `leadNotes` (o al prossimo prompt). Testo: percorso assoluto
   atteso, «il file non c'è / è vuoto», scrivilo e verifica con `test -s <percorso>`. Una volta per nota; riga di log.
5. **Skill `handoff`**: percorso = radice del repo principale (`dirname "$(git rev-parse --path-format=absolute
   --git-common-dir)"`, o la root del progetto fuori da git) + `.claude/handoff/pending/…`; prima della riga finale
   (principale e variante agente) `test -s <percorso>`; se fallisce, riscrivi, non annunciare.
